# note Market Planner — iPhone版

note市場を分析して、記事本文を書く前の「企画」を作るツールです。

## 主な機能

- noteの #タグ 新着ページから候補記事を取得
- 直近30日など期間指定
- 同一URLは6時間以内に再取得しない
- タグ内スキ中央値以上、かつ最低30スキで選別
- 8観点で0〜10点のルールベース分析
  - フック
  - 課題設定
  - 具体性
  - 信頼性
  - 構成
  - 読みやすさ
  - 実行可能性
  - 独自性
- 60点以上の記事から「型」を抽象化
- 他者記事本文はDBに保存しない
- 市場タイトルの頻出語・勝ち型からテーマ候補10本を生成
- 選んだテーマから
  - タイトル
  - コアメッセージ
  - 記事構成
  - 各章の役割
  - 各章に書く内容
  - 筆者本人から必要な実体験
  を生成
- 公開後にスキ数 / 販売数 / 売上を記録
- 自分の記事で効いた「型」を集計
- JSONバックアップ

## AI APIについて

この版はOpenAI APIを使いません。
追加のAI API料金は発生しません。

その代わり、8観点採点・型抽出・テーマ生成はルールベースです。
意味理解を使うAI分析より精度は落ちますが、市場分析と記事企画の土台作成までは自動で行えます。

記事本文を最終的に書く際は、完成した企画をChatGPTに渡して執筆する運用を想定しています。

## iPhoneで使う

アプリ自体はWebへ一度デプロイします。
デプロイ後はSafariでURLを開くだけです。

### Streamlit Community Cloudを使う場合

1. GitHubで新規リポジトリを作成
2. このフォルダ内のファイルをアップロード
3. Streamlit Community CloudをSafariで開く
4. GitHubリポジトリを接続
5. Main file path を `app.py` にする
6. Deploy
7. 発行URLをSafariで開く
8. Safariの共有 →「ホーム画面に追加」

OpenAI API Keyは不要です。

### 注意

Streamlit Community Cloud等の無料環境では、ローカルSQLiteファイルの永続保存が保証されない場合があります。
このため「データ」タブから定期的にJSONバックアップしてください。

本格運用時はSupabase / Neon / Turso等へのDB移行を推奨します。

## note側の変更について

noteの公開HTML構造が変更された場合、記事URLやスキ数の取得処理は調整が必要になる可能性があります。
サイトへの負荷を抑えるため、取得間隔と同一URL6時間制限を実装しています。
